# 2D Maze Generator

This is a maze generator that I continue to add options to so the user has increased control over the mazes generated. The mazes can be exported as image files for dungeon planning, book covers, graphic design, etc. and I plan to add ways to alter them visually so they are more useful for these types of projects.
[Try it out!](shanzcraft.github.io/2D-maze-generator/)

## Tech Stack
- JavaScript
- HTML & CSS
